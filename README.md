# Spark IPTV Player (مشغّل IPTV الذكي)

تطبيق مشغّل IPTV احترافي أصيل (Native Android) مبني بأحدث تقنيات **Kotlin** و **Jetpack Compose** و **Media3/ExoPlayer**، مع دعم كامل للهواتف والتابلت وأجهزة **Android TV** (D-Pad Navigation).

---

## 🌟 الميزة الجوهرية: مصدر الصوت الخارجي (Dual Player External Audio Engine)
- **مشغّل مزدوج متزامن:**
  - **Player A:** مشغّل الفيديو الرئيسي (Live / VOD).
  - **Player B:** مشغّل صوتي فقط (Audio-only) لقنوات التعليق الصوتي أو الإذاعات المشتقة من نفس اشتراك Xtream.
- **مزامنة فورية دون انقطاع الفيديو:**
  - فتح قائمة الصوت الخارجي فوري بنسبة 0ms اعتماداً على ذاكرة التخزين المحليّة (Room Database & In-Memory Cache) دون أي طلبات شبكة جديدة عند فتح القائمة.
  - عند اختيار المصدر الصوتي، يتم كتم صوت Player A فورياً دون إعادة تحميل الفيديو، دون تجميد، ودون إعادة تشغيل.
  - شريط ضبط تأخير وتزامن الصوت (Audio Delay Offset) من **-5000ms** إلى **+5000ms** بخطوات 50ms، مع أزرار تقديم وتأخير سريعة.
  - مراقبة تلقائية للانجراف (Drift Watchdog): فحص دوري كل 1.5 ثانية لإعادة المحاذاة التلقائية إذا تجاوز الفارق 500ms.
  - حفظ إعدادات الصوت والتأخير لكل قناة بشكل دائم في قاعدة البيانات.
  - إيقاف الصوت الخارجي واستعادة الصوت الأصلي للقناة بضغطة زر واحدة.

## 📱 أقسام وشاشات التطبيق
1. **شاشة البداية (Splash):** فحص الترخيص وحالة التجربة المجانية، وتهيئة القنوات.
2. **شاشة التفعيل والدخول (Activation):**
   - تصميم تذكرة أنيق يعرض معرّف الجهاز (Device ID) مع زر النسخ السريع.
   - متابعة الفترة التجريبية (7 أيام) وتفعيل الأكواد.
   - تبويبات تسجيل الدخول عبر **Xtream Codes** (سيرفر، مستخدم، كلمة مرور) أو روابط **M3U/M3U8**.
   - خيار البدء بالتجربة الفورية (Instant Demo) المدمجة مسبقاً.
3. **الملفات الشخصية (Profiles):** دعم تعدد المستخدمين، ملفات الأطفال (Kids Mode)، وقفل PIN.
4. **الرئيسية (Home Dashboard):** شريط "متابعة المشاهدة"، القنوات المفضلة، الأقسام الرئيسية، والأفلام المقترحة.
5. **القنوات المباشرة (Live TV):** تصفح حسب التصنيفات (رياضة، أخبار، ترفيه)، بحث لحظي، مفضلة، وعرض تفاصيل القناة.
6. **مكتبة الصوتيات (Audio Library):** عرض قنوات التعليق الرياضي العربي، محطات الراديو، والبودكاست مع مشغّل صوتي مستقل في الخلفية.
7. **الأفلام (Movies VOD) والمسلسلات (Series):** استعراض البوسترات، التقييم، سنة الإنتاج، تفاصيل المواسم والحلقات.
8. **المشغّل الاحترافي (Player):** ملء الشاشة، التحكم بالإيماءات، نسب العرض (Fit, 16:9, Zoom, 4:3)، سرعات التشغيل، القفل، وزر الصوت الخارجي الذهبي.
9. **البحث الموحد (Unified Search):** بحث فوري شامل في القنوات، الأفلام، المسلسلات، ومصادر التعليق الصوتي.
10. **الإعدادات (Settings):** إدارة الحساب والاشتراك، ضبط حجم الـ Buffer، مسح الكاش، التحكم الأبوي، وسياسة الخصوصية.

## 📺 تجربة Android TV
- دعم تنقل كامل عبر أسهم الريموت (D-Pad).
- إطار ذهبي بارز (`GoldPrimary #F5A623`) وحركة تكبير ناعمة عند التركيز على أي عنصر.
- متوافق مع معايير شاشات التلفاز الكبيرة دون الاعتماد على شاشات اللمس.
